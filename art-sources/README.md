# Supplied Gunners artwork

Original JPEGs from the owner's Google Drive Gunners folder are preserved unchanged in gunners-originals. The manifest maps each transparent game sprite to its supplied source. Transparent PNG derivatives are in public/gunners; src/gunner-art.js is the shared lookup for menus, ship crew, and special-attack animations.

Rocketeer (7), Ice Zombie (8), and Crossbow (16) keep their existing art pending matching supplied replacements. Twin Pistols uses IMG_7396, Music Cannon uses IMG_7409, and Clam Cannon uses IMG_7426 (the version with a cannon). Alternate originals remain preserved.

Source originals are outside the published game directories. Artwork changes do not change roster IDs, combat values, ownership, or saves.
